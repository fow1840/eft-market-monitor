# 页面与数据约定

首页和五个页面读取本地缓存；页面刷新不自动访问外网。ETF观察的“更新行情”按钮显式访问行情源。

- 首页：上海时间、沪深300五维状态、来源日期与缺失提示、组合当前/目标占比、偏离和风险建议。
- 今日市场：五维解释和数据覆盖情况。
- ETF观察：七类ETF本地行情、收盘与均线、趋势量能、完整指标表和CSV下载。
- 市场宽度：真实全市场覆盖数据；缺失时明确降级。
- 我的组合：本地编辑金额、类型与目标比例；当前仓位由金额推导，目标合计须100%。分类汇总的仓位约束优先于市场信号。
- 历史记录：7/30/90日与自定义范围的每日快照。

布局使用可伸缩表格与图表。组合金额和真实资产不提交Git，不发往外部AI。五维不完整时风险模块接收“数据不足”，不会误用“中性”作为可买入依据。
