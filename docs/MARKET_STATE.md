# 五维市场状态规则
五维输入是趋势、量能、份额、估值和宽度的分类结论，输出只有强、改善、中性、偏弱、弱，以及逐维原因和完整性标记。
任何一维缺失都输出中性并明确“数据不完整，中性不代表低风险”，禁止当作风险解除。
趋势与宽度均弱时为弱，单一趋势或宽度弱时为偏弱。趋势强且宽度强、其余三维至少两维支持且没有负面维度为强；较温和的趋势与宽度改善组合为改善。至少两项辅助维度负面时为偏弱；其他情况中性。
无数值评分，无交易指令；仓位和风险限制独立优先。阈值是待历史验证的研究规则，不是已证实策略。
22组完整场景、5组缺失场景及非法/无数据检查。所有输入应为同一截止日已知数据，调用方负责日期对齐与来源校验。
