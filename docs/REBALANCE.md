# 持仓再平衡

在 Streamlit 侧栏选择“持仓再平衡”，上传 `.xlsx`。支持现有总账的“当前持仓”与“目标组合”结构，重新上传更新表即可重新计算。文件及个人金额不写入项目数据库、日志、报告或Git。

## 输入与检查

- 当前持仓：账户、基金名称、当前金额(元)、资产桶；可选细分类、重复/重叠组。
- 目标组合：资产桶、目标比例（可编辑），优先读取该常量列，不使用旧公式缓存。其他支持名称见导入模块。
- 比例可为0.35或35%，合计必须100%；未知桶、空名称、负数、非有限数字、未缓存金额公式等拒绝分析，不静默修正。
- 可选基金目标仓位使用总组合比例，同桶基金目标必须完整且合计等于桶目标。
- 可选可赎回、赎回限制、持有期、最早赎回日。缺失或无法判断均人工确认；未满持有期/未来赎回日优先于错误的“可赎回”标记。
- 确认过实际规则后，可在当前持仓添加“可赎回”列填写“是/否”，并填写最早赎回日、限制等。不得仅凭基金名称猜测到期。

## 金额规则

1. 总资产按当前金额重算，不信任Excel旧仓位公式。
2. 最终桶目标金额=总资产×目标比例，偏离=当前占比−目标占比。默认绝对偏离**大于5个百分点**才触发；恰好5不触发。
3. 无基金目标时按桶内现有金额比例分配最终目标。这是确定性分摊，不是基金优选。明确基金目标时，也单独检查基金偏离。
4. 最终目标调整额=最终目标金额−当前金额；本轮默认取其中25%，分币精度向零舍入，不超出本轮额度。
5. 资金先卖后买；买入总额不得超过计划卖出。资金不足按计划比例缩减买入，剩余明确列为待分配现金。不虚构新增资金。
6. 理论计划假定赎回条件确认；保守计划只使用已明确可赎回的减仓资金。未知/受限卖出不能融资。**已确认计划仍非真实账户可用余额，必须等待实际到账并核查交易条件。**
7. 重复基金跨账户保留合法持仓并提示，不自动删除。主题重叠金额不相加当作总资产；没有独立主题目标不凭空断言主题超配，可输入主题上限（0—1）检查并暂停新增。资产桶整体超配始终检查。
8. 未持有基金的目标桶显示“待指定基金”，不能自动生成基金推荐或可执行买入。
9. 市场趋势不进入金额计算；说明来自规则模板，不调用LLM自由生成金额，不自动下单。

例如合成组合1000元，核心100元、主题900元；目标70%/30%。最终差额+600/−600元，本轮理论计划+150/−150元。若主题赎回未确认，保守模拟金额均为0；确认可赎回且实际资金到账后，才有条件按计划进行人工操作。

## 输出与限制

页面提供当前/目标对比、偏离、每只基金动作、最终差额、本轮计划、已确认金额、持有期说明与两套模拟组合。金额为正表示买入，负表示减仓。CSV仅在用户下载时生成，文本防Excel公式注入；下载文件含个人资料，用户自行保管。

未计手续费、税费、到账滞后、锁定份额或基金价格变动，需人工核查。按实际成交结果更新原Excel的金额与限制字段后重新上传，不将上轮模拟金额冒充成交金额。

测试全部使用人工工作簿/数据；用户原始工作簿仅本地兼容性验证，未提交。运行测试：

```bash
pytest tests/test_holdings_excel.py tests/test_rebalance.py tests/test_rebalance_page.py -q
```

资金预算按全组合汇总；跨账户资金需人工调拨，并非同账户即时可用。未确认账户调拨条件前不应直接照模拟执行。
